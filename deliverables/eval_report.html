Two generic-phrase gaps found there (“SHAREHOLDERS” as a name, “Equity Shares” as a company) were added to the config filters.

Method

Many finders, one judge. Regex + checksum validators, a PIN-anchored address finder, the GLiNER2-PII encoder, an LLM on hard pages, and cross-page propagation of confirmed names are unioned; a rule judge applies type precedence, shape gates for identifiers, a regulator allowlist, generic-role filters and confidence thresholds. Entities are clustered across pages and given HMAC-seeded, token-level consistent fakes; the output is written in the input's own format (PDF true redaction / DOCX in-place edits), then verified by searching the output for every original value.
