Method in one paragraph

Many finders, one judge. Regex + checksum validators, a PIN-anchored address finder, the GLiNER2-PII encoder, a local LLM (Ollama qwen2.5:7b) on hard pages, and cross-page propagation of confirmed names are unioned; a rule judge applies type precedence, a regulator allowlist, a generic-role filter and single-finder confidence thresholds. Entities are clustered across pages and given HMAC-seeded, token-level consistent fakes; the output is written in the input's own format (PDF true redaction / DOCX in-place run edits), then verified by searching the output for every original value.
